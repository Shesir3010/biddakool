# Research

Supporting research material for Biddakool: benchmark studies, source extractions, competitor brochure notes, and raw working evidence.

This folder is **not** part of the six-document module signature and is never cited as current product truth. Product documents reference it only from their References sections.

## Conventions

- Filenames name the *source*, not the product: `<Source>-<Topic>.md` (e.g. `CompetitorX-Brochure-Research-Notes.md`).
- Raw extraction notes and working journals live here; curated, official conclusions belong in module documents.
- Files here may be edited freely — they are working material, not frozen archives (frozen/superseded documents belong in [`00-products/archive-files/`](../00-products/archive-files/README.md)).
