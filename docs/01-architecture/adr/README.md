## Rules

- ADRs are numbered sequentially: `ADR-0001`, `ADR-0002`, … Filename: `ADR-<nnnn>-<kebab-title>.md`.
- A file format template ships in `docs-template/adr-template/`.
- **ADRs are never edited.** A reversed or revised decision gets a new ADR that supersedes the old one, which stays in place.
- Product documents may reference an ADR, but never restate its decision — link to it.
